# 🏆 Treasure Maze Game (C++)

A console-based treasure maze game built in C++ using Visual Studio 2022.

## 🎮 Features
- Random maze generation using DFS
- Multiple difficulty levels
- Unicode emojis & colored console output
- Treasures with scoring system
- Lives & levels

## 🛠 Tech Used
- C++
- MSVC (Visual Studio 2022)
- Windows Console API

## ▶️ How to Run
1. Open project in Visual Studio 2022
2. Press Ctrl + F5
